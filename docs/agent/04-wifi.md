# 04 联网（Wi-Fi）

## 架构（先让用户明白）

D50 的 Wi-Fi 由板载 **ESP8684** 提供，它只是一块"网卡"。**连哪个网络、何时连、断线怎么办全由 P4 的固件决定**（`main/wifi_manager.c`）。
P4 里用的是标准 `esp_wifi_*` 接口。**仅支持 2.4 GHz 网络。**

## 前提：ESP8684 要先烧一次从机固件（一次性）

ESP8684 里必须有 esp-hosted SPI 从机固件，否则开机自检的 **Wi-Fi 一项会显示 FAIL**。成品和步骤在 `c2_firmware/README.md`，需要飞线（用户要动手），
**转串口必须是 3.3 V 电平，VCC 不接**。烧过之后不需要再烧。

## 给设备连上网：先问用户要名称和密码（推荐）

对用户说明：最省事的做法是**直接在对话里告诉我 Wi-Fi 名称和密码**。说明这些信息只会写进本机一个**不会被提交的文件**，不会上传。然后：

1. 复制 `main/wifi_credentials.h.example` 为 `main/wifi_credentials.h`（该文件已被 `.gitignore` 忽略），填入名称和密码。
2. `idf.py build` 并烧录。设备开机后静默连接（界面上不显示联网状态）；要确认是否连上，可以用路由器后台或 ping 设备的 IP。
3. **绝不要**把密码写进别的源文件、文档、示例或提交信息，也不要建议用户把它推到仓库。

## 用户不愿意提供密码：热点配网

默认固件**不会**自己开热点，界面上也**没有任何联网提示**（没有 Wi-Fi 信息时设备安静地保持离线）。
用户不想把密码告诉你时，由**你**在本地开启配网模式：

1. 把 `main/open_config.h` 里的 `D50_WIFI_PORTAL_ENABLE` 改为 `1`（确保没有 `wifi_credentials.h`，或其中名称密码留空）。
2. `idf.py build` 并烧录。设备开机后会进入专用的 **"Wi-Fi 配网"页**（不是首页），屏幕上显示热点名 `D50-Setup-XXXX` 和密码 `d50setup`。
3. 让用户用手机连这个热点。多数手机会自动弹出配网页；没弹出就用浏览器打开 `http://192.168.4.1`。
4. 网页里选择或输入 Wi-Fi 名称和密码，点"保存并连接"。设备连接成功后会显示"已连接"和 IP，几秒后**自动重启**，之后每次开机自动静默连接。
5. 配好之后可以把 `D50_WIFI_PORTAL_ENABLE` 改回 `0` 再烧一次（不改也不会重复进入配网页，只要设备里已保存 Wi-Fi）。

连不上（密码错、信号弱、5 GHz）时，配网页会提示"连接失败"，热点保持开启，用户可以重新填。

## 连接优先级与修改网络

设备开机时按这个顺序取 Wi-Fi 信息：**① 设备闪存里保存的（热点配网存的）→ ② `wifi_credentials.h` 里的默认值 → ③ 都没有就保持离线。**
掉线后会自动重连。

因此：用户用热点配过网之后，再改 `wifi_credentials.h` 是**不会生效**的。要换网络，先清掉设备里保存的信息（只擦 NVS 分区，不影响固件）：

```bash
python -m esptool --chip esp32p4 -p <串口> erase-region 0xA000 0x6000
```

（擦除前请和用户确认串口无误。）清掉后重启，再按上面的流程重新配置。

## 自己写联网代码

`wifi_manager_init()` 完成链路与 STA 启动；之后用 `esp_http_client`、`esp_mqtt` 等标准组件即可。
`main/selftest.c` 里的 `selftest_wifi()` 是最小的"链路是否正常"示例（扫描）。
