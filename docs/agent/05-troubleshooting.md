# 05 排障

## 先做：看开机自检

开机后屏幕第二页有 8 项自检，逐项显示 `OK` / `FAIL`。**请用户拍一张这一页的照片**，它几乎就是诊断的第一步。

| 自检项 | FAIL 的常见原因（由易到难） |
| --- | --- |
| 显示屏 | 能看到这一页说明屏幕本身没问题 |
| 灯效 | 灯数据线（按键灯 GPIO7 / 底部灯 GPIO0）或 `5V_RGB` 供电异常；自己改代码时 RMT 资源被占用 |
| PSRAM | 一般不会 FAIL；FAIL 说明配置被改动或硬件问题 → 转人工 |
| 扬声器 | 编解码器 I2C（GPIO14/15）或 I2S 初始化失败；功放使能 GPIO53；多半是改过 BSP |
| 麦克风 | 同上；USB 麦克风占用时不能再读 |
| 按键旋钮 | 只确认输入任务已启动；真正测试请用户按键，看屏幕右下角"最近输入"文字 |
| USB | USB 初始化失败；TinyUSB 版本或描述符被改 |
| Wi-Fi | ① ESP8684 无从机固件（**最常见**）→ 见 `04-wifi.md` 飞线烧录；② SPI 引脚在 `sdkconfig.defaults` 里被改；③ 硬件焊接问题 → 转人工 |

## 常见现象

| 现象 | 处理 |
| --- | --- |
| 编译报 IDF 版本 / Python 版本错误 | 必须 ESP-IDF v6.0.2；先 `unset IDF_PATH IDF_PYTHON_ENV_PATH` 再 `source export.sh` |
| 依赖下载失败 | 检查网络；删 `managed_components/` 和 `dependencies.lock` 后重新 `idf.py build` |
| 找不到串口 / 烧录失败 | 看 `01-getting-started.md` 的端口说明与 BOOT+RST 兜底方法；换数据线（有些线只能充电） |
| 屏幕不亮 | 先看有没有声音与灯；重烧本仓库固件对照；仍不亮 → 转人工 |
| 开机一直响 | 本仓库固件已修复；确认固件是本仓库版本，且 `bsp_audio.c` 里 `auto_clear_after_cb = true` 没被删 |
| 某个按键没反应 | 看屏幕右下角"最近输入"；区分单个还是全部；对照 `02-hardware-and-pins.md` |
| Wi-Fi 连不上（自检 OK） | 是不是 5 GHz？密码是否正确？是否被路由器 MAC 过滤？默认界面不显示联网状态；让用户走热点配网重填，或让设备接串口看日志 |
| 热点 `D50-Setup-XXXX` 搜不到 | 先确认已按 `04-wifi.md` 开启 `D50_WIFI_PORTAL_ENABLE` 且设备里没有保存过 Wi-Fi；自检里 Wi-Fi 须为 OK；重启设备；手机别开"自动切换到更好的网络" |

## 需要日志时

设备主日志在 UART0（P4 的 GPIO37/38，引到板上测试点），需要 3.3 V 的 USB 转串口。让用户提供：完整终端输出、开机自检照片、固件版本、ESP-IDF 版本。
